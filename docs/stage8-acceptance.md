# 阶段 8 验收：`notice` 通知页

日期：2026-11-24 · 版本 0.9.0

## 为什么是这一页

班级宣传委员写得最多的不是 PPT，是群通知。通知有固定结构：**一句话结论 → 时间 / 地点 / 对象 →
要带什么 → 找谁**。过去这五段要么堆成一段文字，要么临时排版；`notice` 把它变成一页。

## 槽位

| 槽位 | 上限 | 必填 | 说明 |
| --- | --- | --- | --- |
| `title` | 4–24 | ✅ | 一句话结论，落在页面上三分之一 |
| `when` | 2–26 | ✅ | 时间，放得下「11 月 28 日（周五）14:00–16:00」 |
| `where` | 2–26 | ✅ | 地点 |
| `who` | 2–24 | ✅ | 对象（谁要来） |
| `todo` | 0–4 条，每条 ≤16 | — | 要带 / 要做的事，画成空心方块 |
| `note` | ≤30 | — | 截止、请假、备注 |
| `contact` | 2–30 | ✅ | 联系人 / 报名找谁，固定在页脚 |

## 版式约定

- 标题从 `title` 档起排（不用 display 96），因为下面还有三行信息和一份清单。
- 三行信息用「标签 + 值」两栏，逐行 hairline 分隔；标签 muted、值用正文色。
- 待办是空心方块 + 一条一行，不上序号——通知里勾选比编号更自然。
- **高度预算**：排版前先算各段高度；放不下就依次删掉最后一条待办、再丢 `note`，绝不压到页脚
  （首版没算高度，联系人直接叠在待办上，截图留在了问题记录里）。
- `variant` 只影响标题字号：`impact` 用 `title`，`density` 用 `headline`；行内容不删减。

## 验收口径

| 口径 | 结果 | 证据 |
| --- | --- | --- |
| 一页讲清一件事 | ✅ | 2 页样本（团日活动通知 / 征稿延期通知）`brief` 与 `check` 全绿；`docs/stage8-notice.png` |
| 缺必填项会被拦 | ✅ | 去掉 `who` 后 `brief` 报 `missing`；冒烟有专门断言 |
| 内容多时不压页脚 | ✅ | 3 条待办 + 备注时仍全部落在联系人之上；再加内容会先删待办、再丢备注 |
| 能导出 PPTX | ✅ | `export` 2 页成功，PowerPoint COM 渲染与 SVG 一致：标题、三行信息、勾选方块、联系人都是原生元素 |
| 门禁不放宽 | ✅ | 无新增 skip；冒烟 64/64 |

## 已知边界

- 通知页是纯文字版式，不带照片；要"照片 + 通知"的组合用 `hero` 或 `image`。
- `todo` 最多 4 条；超过就会被挤掉尾部，应该拆到第二页或改用 `process`。
- 没有二维码槽位：报名二维码目前只能作为说明文字或另起一页。
- 字号与行距跟着主题走；`ink-water` 的宋体在通知页上偏文艺，正式通知建议 `paper-stamp` / `navy-brief`。
