# 阶段 11 验收：`chart` 图表页（v0.10.0）

日期：2026-11-24 · 项目：`C:\Users\30139\Documents\deepseek-harness\dsh-deck-studio`

## 用法

```json
{ "file": "03_chart.svg", "archetype": "chart", "variant": "impact",
  "text": {
    "headline": "一学期的产出构成",
    "bars": ["展板 18", "推文 9", "海报 6", "视频 3"],
    "unit": "项",
    "note": "展板占了三分之二，但它也是最容易被反复改的一类。",
    "source": "口径：02-成品，10-26 → 11-24"
  } }
```

`bars` 每条写「标签 数值」，分隔符空格 / 冒号 / 竖线都认。

## 三条口径

| 口径 | 结果 | 证据 |
|---|---|---|
| 柱高按数值归一 | ✅ 18 / 9 / 6 / 3 → 高度比 1 : 0.5 : 0.33 : 0.17（冒烟断言 18 号柱高 > 3 号柱高 × 3） | [stage11-chart.png](stage11-chart.png) 左 |
| 导出后仍可编辑 | ✅ PPTX 里柱子是原生矩形、数值与标签是文本框，不是整页图片 | 同图右 |
| 没数字的柱子被拦 | ✅ `bars` 里写「推文很多」→ `vague` 违规（`kind=vague`），export 直接拒绝 | `data.blockers` |

## 设计取舍

- **不画 Y 轴刻度**：班级汇报只需要"哪一类占大头"。三条淡参考线给高度参照，刻度标签会把这个 1600×900 的版面塞满。
- **柱子用主题 accent**（这页是 blueprint 的 `#9A5B33`），不按数值渐变色阶——六根柱子用六种颜色只会让人找规律。
- **结论条贴着底部**，左对齐正文、右对齐数据来源；`note` 缺省时柱区自动往下让出空间。

## 已知边界

- 只有竖向柱状图；折线、堆叠、饼图未做（`bars` 的数值是离散类别，不适合趋势）。
- 最多 6 根柱子（`slot.max`），超过要拆页或改 `metrics`。
- 不处理负值：`bars` 里的数值按正数归一，负数会被正则漏掉并报"没有可画的柱子"。
- 单位只支持一个统一单位，混合单位（件 + 人）需要改用 `metrics`。
