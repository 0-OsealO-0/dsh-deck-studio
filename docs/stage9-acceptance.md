## 过程中修掉的三个问题

1. **标签白字白底**：`qrLabel` 首版跟随主题色，深色主题下在白卡上看不见 → 固定 `#1B2430`。
2. **通知标题折行**：带 `qr` 后列宽变窄，标题折成两行把时间地点挤下去 → `fitRole(..., 1)` 强制单行，取小一档字号。
3. **待办被误删**：高度预算按窄列重算后仍丢了一条待办 → 标题回到单行腾出高度后两条都在（预算逻辑本身正确，是标题行数把余量吃掉了）。

## 已知边界

- 二维码只支持位图（PNG/JPG/WebP）；插件不生成二维码，需自备（微信 / 问卷星下载图）。
- 白卡固定 236×236 + 标签 34，不随主题或版面缩放；极窄版式（如 4:3）未适配。
- `qr` 只在 `hero` 与 `notice` 上开放；`cover` / `closing` 暂不支持。
