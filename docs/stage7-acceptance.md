# 阶段 7 验收：`hero` 招新大图页原型

日期：2026-11-24 · 版本 0.8.0

## 为什么先做这个

前六个阶段把"讲清楚一件事"的版式补齐了（封面、观点、数据、对比、流程、结尾、图文），
但班级宣传最常见的活其实是**招新 / 活动预告**：一张照片、一句主张、时间地点、怎么报名。
这类页过去只能用手写 SVG 拼，或者退回 dashi 的模板。`hero` 就是补这个缺口。

## 新原型

| 槽位 | 上限 | 必填 | 说明 |
| --- | --- | --- | --- |
| `kicker` | 2–10 | ✅ | 社团 / 活动名，放在照片上沿 |
| `title` | 4–16 | ✅ | 一句话主张，按 `display → title → headline` 自动降档 |
| `subtitle` | ≤30 | — | 补充一句，`density` 变体下不排 |
| `when` | 2–20 | ✅ | 时间 |
| `where` | 2–20 | ✅ | 地点 |
| `cta` | 2–20 | ✅ | 报名方式，画成 accent 色块贴页脚 |
| `image` | — | ✅ | `images/` 里的照片，整页铺满 |

版式从页脚往上排：CTA → 时间地点 → accent 细线 → 副标题 → 标题；标题块过高时整体上移，
不会把 CTA 挤出画布。照片上盖一层比封面更重的压暗层（`0.62 / 0.78 / 0.9 / 0.97`），
因为 hero 的标题落在照片中部，而封面的标题本来就在接近不透明的底部。

| 口径 | 结果 | 证据 |
| --- | --- | --- |
| 一页能讲完招新信息 | ✅ | 3 页样本（impact / density / 观点页）`check` 全绿；`docs/stage7-hero.png` 是 `neon-cyan` 与 `warm-sand` 两套主题的对照 |

| 门禁不放宽 | ✅ | 没有新增 skip 或降级分支；冒烟 62/62 |

## 已知边界

- hero 只负责"一页说清一件事"；横幅、竖版海报这类印刷规格不在原型覆盖范围内。
- 照片是整页铺满，没有做"半幅 + 留白"的构图变体；要那种排版用 `image` 原型。
- 报名二维码目前只能作为照片的一部分，没有独立二维码槽位（下一步可加 `qr`）。
- `hero` 的 `title` 上限 16 字是按投影可读性定的；更长的标题应拆成标题 + 副标题。

## 下一步候选

- `notice` 通知页原型（时间 / 地点 / 对象 / 报名 / 联系人五段式），对应班级群通知的固定结构。
- `qr` 槽位：把报名二维码单独摆位，不依赖照片。
- `hero` 的第二种构图：左文右图或上文下图，用于横版海报以外的场景。
